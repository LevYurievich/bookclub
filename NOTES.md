# Мой книжный дневник — заметки о проекте

Сервис для учёта прочитанных книг. Делается в Lovable, код хранится в этом репозитории.

## Что умеет сервис (этап 1)

- Регистрация и вход по email и паролю.
- Уникальный логин (username) при регистрации.
- Личный кабинет: имя, логин, аватар, счётчики книг по статусам.
- Книги: название, автор, обложка (загрузка файла), статус («Читаю сейчас», «Хочу прочитать», «Прочитано»), личный рейтинг 1–10, мнение, краткий конспект, даты чтения.
- Страница «Мои книги»: фильтр по статусу, поиск, сортировка.
- Рецензия по умолчанию приватная. Её можно опубликовать: появляется публичная ссылка, которую можно отключить.
- Скачивание рецензии в PDF (генерация на клиенте).

## Решения

- Рецензии приватные по умолчанию.
- Публичная страница рецензии показывает логин владельца, но не другие личные данные.
- Обложки хранятся в файловом хранилище, в базе только ссылка.
- Доступ к данным ограничен правилами Row Level Security.
- Бэкенд: встроенный в Lovable (Supabase / Lovable Cloud).

## Этап 2 (потом)

- Книжные клубы (группы): создание группы, приглашение участников по логину или ссылке.
- Выбор книги для обсуждения в группе и комментарии.
- Участники группы видят рецензии друг друга на книги, которые обсуждаются в группе.

## Как продолжать

1. Сначала сделать регистрацию, личный кабинет и список книг.
2. Потом страница книги с рецензией и публикацией.
3. В последнюю очередь PDF.
4. Группы — этап 2.

Исходный промпт для Lovable: см. историю чата (здесь он не дублируется, чтобы не устаревал).
